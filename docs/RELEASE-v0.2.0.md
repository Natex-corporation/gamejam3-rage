# Rage: Clay Demo 0.2.0

Download **Rage-Clay-Demo-Windows-x64.zip**, extract the entire ZIP, and double-click **Rage Demo.exe**. Windows 10/11 x64; offline, single-player. No separate game copy, Unity Editor, or developer tools are required to play.

- Six districts with permanent unlocks and selectable starting districts.
- Lobbers, shieldguards, menders, splitters, rushlings, and the two-phase Kiln King.
- Eight permanent upgrade paths, including dash, ricochet, forked shots, and rhythm damage.
- Textured clay menus, original clay boss artwork, four languages, remapping, and pause/projectile fixes.
- Agent discovery through AGENTS.md, llms.txt, demo-manifest.json, and CodeMeta.

**Assets:** The Windows ZIP is the game. Rage-Developer-Kit.zip contains the untouched original assembly and Mono.Cecil 0.11.6 plus its license for rebuilding the expansion from source. SHA256SUMS.txt verifies both ZIPs. The release manifest records the source commit and playable ZIP hash.

The custom C# source and project-owned generated artwork are MIT licensed. Original game assets, fonts, audio, and bundled dependencies retain their existing terms; see THIRD_PARTY_NOTICES.md. This is an expansion source checkout rather than a complete Unity Editor project.

Validation includes localized menu layouts, progression/save persistence, projectile boundaries, enemy and upgrade mechanics, boss phases, and a fresh input-driven six-district expedition. See docs/QA.md for evidence and limits. Human playtime and broad hardware compatibility remain unmeasured.
