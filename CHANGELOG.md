# Changelog

## 0.1.0 — 2026-11-14

First public source release of the GameJam3 Rage refinement layer.

- Match added menus to the game's warm paper panels and clay palette.
- Share rounded styling across settings, HUD badges, and localized captions.
- Retain handwritten lettering, hover feedback, and visible keyboard focus.
- Include four-language menus and dialogue, keyboard remapping, graphics settings, pause fixes, generated stages, and checkpoints.
- Add a compatibility-checked build script with install backups.
- Add documentation, screenshots, contribution guidance, and an MIT source license.
